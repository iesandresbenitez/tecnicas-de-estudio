# ESTUDIA+ · Aprende a aprender

Aplicación web educativa del IES Andrés Benítez para consultar técnicas de estudio, experimentar con estrategias y practicar habilidades de memoria, atención y razonamiento.

## Enfoque
- Público: alumnado de ESO, Bachillerato y Formación Profesional.
- Uso abierto, sin registro ni cuentas.
- No permite subir documentos, imágenes ni materiales personales.
- No incluye planificación personal ni almacenamiento de expedientes.
- Contenidos y actividades precargados en la propia aplicación.
- Cuestionario orientativo: ofrece estrategias para experimentar; no etiqueta estilos de aprendizaje ni diagnostica capacidades.
- Sin servidor ni base de datos.

## Secciones
1. Inicio.
2. Biblioteca de técnicas de estudio con ejemplos y pasos.
3. Cuestionario «Descubre qué te puede funcionar».
4. Entrenamiento de memoria, atención y razonamiento.
5. Retos de comprensión y aplicación de estrategias.
6. Consejos para estudiar.

## Publicación en GitHub Pages
1. Abre Settings → Pages.
2. En Build and deployment, selecciona Deploy from a branch.
3. Elige la rama main y la carpeta /(root).
4. Guarda y espera a que finalice la publicación.

La web utiliza rutas relativas para funcionar desde el subdirectorio del proyecto en GitHub Pages.

## Archivos
- index.html: estructura y navegación.
- styles.css: identidad visual corporativa STEAM 4.0 y diseño responsive.
- app.js: contenidos, cuestionario, juegos y retos.
